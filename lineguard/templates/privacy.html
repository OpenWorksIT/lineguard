LineGuard privacy policy

LineGuard software and the LineGuard phone app, by OpenWorks IT (Pty) Ltd, South Africa. Last updated 31 October 2026.

LineGuard turns thermal photos of powerlines into a list of hotspots, and the LineGuard app guides field technicians to each one. This policy explains what information the app and the LineGuard server handle, where it is kept and who can see it.

Who is responsible for your data

LineGuard runs on a server chosen by the organisation that uses it. That is usually a laptop belonging to the organisation, or a server it controls. The organisation that runs the LineGuard server is responsible for the information on it. Where OpenWorks IT hosts a LineGuard server for an organisation, OpenWorks IT processes that information only on the organisation's behalf and only to provide the service.

OpenWorks IT does not run any analytics, advertising or tracking in the app, and does not receive any information from the app unless OpenWorks IT is hosting the server the phone is paired with. The one outside service built into the app is Google's QR code scanner (see below).

What the LineGuard server handles

The server stores the drone photos it is given, the hotspots found in them, the names of paired phones and the changes made from them. It stores a scrambled form (a hash) of each phone's access key, not the key itself. If the organisation turns on power-line lookups, the server asks the public OpenStreetMap Overpass service for power lines near each flight, which shares only the flight's map area.

Connections

An online LineGuard server is reached over an encrypted (HTTPS) connection. A LineGuard laptop in a vehicle is reached directly over the laptop's own Wi-Fi network, which is protected by that network's password. Each phone must be paired with a one-time code from the dashboard, and the organisation can unpair a phone at any time.

Keeping and deleting data

  • In the app, Settings → Connections → Forget removes a pairing and everything saved from that LineGuard on the phone. Removing the app removes all of its data.
  • On the server, the organisation running LineGuard can unpair phones and delete flights from the dashboard. To ask for information about you to be removed, contact that organisation, or contact OpenWorks IT if it hosts the server.

Children

LineGuard is a work tool for powerline maintenance teams and is not directed at children.

Your rights

Under South Africa's Protection of Personal Information Act (POPIA) and similar laws, you can ask what personal information is held about you and ask for it to be corrected or deleted. Contact the organisation that runs your LineGuard server, or OpenWorks IT at info@openworks.co.za.
